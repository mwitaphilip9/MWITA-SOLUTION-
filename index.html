M-Pesa payment instructions

Important: Only pay using the official receiving details confirmed by the MWITA SOLUTION administrator. Do not send money to an unverified number.
  1. Choose your level, subject and material above.
  2. Ask the administrator for the official M-Pesa Send Money number.
  3. Send KSh 20 for each paid subject material you selected.
  4. Keep your M-Pesa confirmation message and transaction code.
  5. Submit the transaction code directly to the administrator using the official contact channel provided by them.
  6. The administrator checks the payment and then provides access to the material.

Receiving number: Obtain the verified number directly from the administrator. It is not published on this demo page.

Payment submission and automatic access are not connected yet. This GitHub website is a static site and does not securely store payment references. Do not enter private payment details into this demo page.
